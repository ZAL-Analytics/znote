Installing

How do I install the file I just downloaded?

Windows

Double click the .exe and follow the installer. Windows may warn that the publisher is unknown, because the installer is not signed with a paid certificate. Choose More info then Run anyway.

macOS

Open the .dmg and drag znote into Applications. The app is not notarised, so the first launch is blocked. Open System Settings, then Privacy & Security, and choose Open Anyway next to the message about znote.

Linux

Open a terminal in your downloads folder and run the line for your distribution.

sudo apt install ./znote_*_amd64.deb        # debian 13+, ubuntu 24.04+
sudo dnf install ./znote-*.x86_64.rpm       # fedora, opensuse
sudo pacman -U ./znote-*.pkg.tar.zst        # arch

The assistant keeps provider keys in your desktop's password store, such as GNOME Keyring or KWallet.

From source

With a Rust toolchain and the WebKitGTK development headers installed:

cargo install znote --features tauri/custom-protocol
How do I know the file is genuine?

Every file has a .sha256 checksum and a .asc OpenPGP signature next to it on the release page. The steps to check them are in Verifying a download.
